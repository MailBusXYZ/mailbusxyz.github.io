Mailbus loads its typeface from this folder so the site makes no requests to
third parties (no Google Fonts or other CDNs).

To finish the setup, add one file here:

  SchibstedGrotesk-VariableFont_wght.ttf

Schibsted Grotesk is free under the SIL Open Font License. Download the family
from https://fonts.google.com/specimen/Schibsted+Grotesk and copy the variable
font file from the zip into this folder, keeping the file name above.

Until the file is added the site falls back to the visitor's system font.
